# Neelam React Todo App

A lightweight, dependency-free React todo list that runs directly in the browser. It uses modern React APIs delivered via [esm.sh](https://esm.sh/) so you can open the `index.html` file without a build step or tooling setup.

## Features

- Add, rename, complete, and delete todo items
- Filter between all, active, and completed tasks
- Toggle all tasks at once or clear completed items
- Persists tasks automatically to `localStorage`
- Responsive layout with a modern, accessible design

## Getting started

1. Clone the repository and open the project folder.
2. Open `index.html` in a modern browser (Chrome, Firefox, Edge, or Safari).
3. Start managing your tasks!

> **Note:** The app pulls React and React DOM from a CDN. Your browser will need an internet connection the first time the page loads.

## Project structure

```
├── index.html        # Entry point that bootstraps the React app
└── src
    ├── app.js        # React components and application logic
    └── styles.css    # Styling for the interface
```

Feel free to customize the styling or extend the functionality for your workflow.
